# Phase 6G2 — bounded three-plane MPR geometric contour agreement

**Base:** `f435b2990373e502f0cf2bbf9aea4842a17ea819` on `phase6-accurate-surfaces`.

Read-only, numerical, synthetic-only increment. Compares **Patient-LPS** intersection contours of the candidate mesh and the source selected-label mask's padded-0.5 marching-cubes polygonal interface on explicitly supplied **axial, coronal and sagittal MPR world planes**. The existing `dicom_mpr.py` descriptor supplies plane position, LPS axes, pixel dimensions, extents, vertical reversal and spacings; do **not** substitute acquisition index planes. The mask can be a full selected-label mask or a bounded cropped ROI with the **correctly translated ROI affine**, but all MPR descriptors must be from the same source study. The caller must verify study, label-map, label, selected slices and candidate surface provenance before numerical qualification (Phase 6G3).

The helper obtains nonzero 2D contour segments by intersecting filled triangles with each MPR plane, then uses deterministic contour-length-stratified **segment midpoints**. Each sampled source point gets the exact shortest **point-to-line-segment** distance in millimeters, in each direction. It reports sample/total segment counts, sample fraction, mean, p95 and maximum *sampled* distance. This is **not** a full contour Hausdorff distance; small disconnected structures can be omitted by sampling. A plane with no contours is explicitly `no_contours_at_selected_slice`, and a one-sided missing contour is `missing_contour_on_one_side`; neither yields a fabricated zero. Coplanar faces and exceeded mask/mesh/intersection/search budgets fail closed. Intersections at acquired-volume edges use a padded virtual exterior; reference edges beyond the displayed MPR center-voxel FOV are reported, not silently erased.

**Not implemented in 6G2:** raster segmentation-overlay pixel equivalence, actual browser compositing, real-study/provenance integration, multi-slice exhaustive coverage, clinical validation, or numeric acceptance thresholds. In particular, the MPR grayscale/overlay raster uses its own sampling; these contour measurements alone **cannot** establish pixel-perfect on-screen alignment. Phase 6G3 must explicitly bind provenance, evaluate appropriate real-study slices/coverage, and report unresolved or unqualified cases honestly. The helper never changes source labels, authoritative surfaces, normals, viewer presentation, clipping, or production.

Run `VOXELATLAS_SURFACE_PYTHON="$HOME/.local/share/voxelatlas/surface-runtime-phase6a/bin/python" bash scripts/run_phase6g2_mpr_checks.sh` from the development checkout. Synthetic tests cover anisotropic rotated LPS geometry, all three world-plane definitions and vertical orientations, exact self-agreement, shifted meshes, segment-interior distances, missing contours, acquired-volume edge, invalid descriptor and coplanar-face rejection. Prior 6G0/6G1 numerical tests run as regression.
