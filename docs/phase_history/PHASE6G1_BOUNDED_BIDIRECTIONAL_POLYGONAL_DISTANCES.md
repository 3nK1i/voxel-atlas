# Phase 6G1 — bounded bidirectional polygonal interface distances (synthetic foundation)

Baseline: `07b5cfd35e2a815d6f88ad214d90389e5d487525`, branch `phase6-accurate-surfaces`.

Additive read-only numerical module; no study loading, API, UI, production, canonical artifacts, label edits or presentation changes. Input is an already-selected full boolean label mask (or a properly translated tight ROI with virtual-zero exterior), the **mask index-to-Patient-LPS** affine, and the candidate accurate/refined mesh vertices in Patient LPS and triangle indices. The caller must check source label id/hash, source ROI, affine, candidate mesh id/hash and quality before interpreting any result. This initial helper does not enforce real-study provenance or fetch surfaces; 6G3 must integrate that binding. Neither source label mask nor candidate arrays are modified.

The reference polygonal interface is independently generated with the Phase 6A worker's zero padding + Lewiner marching cubes at 0.5, transformed to Patient LPS. This is **polygonal marching-cubes interface geometry**, not an exact continuous trilinear isosurface. Triangle-centroid samples selected deterministically by cumulative triangle area are measured against **filled target triangles**, including their interiors, via an exact Euclidean point-to-triangle nearest distance search; both candidate→reference and reference→candidate directions are reported in physical mm. Unlike the 6G0 local gradient proxy, each individual reported sample distance is a true geometric nearest distance to target triangles. The sample set does not cover every point on the two surfaces, and this result is **not** an exact surface Hausdorff, an MPR registration test, signed distance, a Dice score, or proof of diagnostic validity. Small faces or disconnected components can be missed; sample coverage is an explicit fraction of source triangles, not a physical coverage guarantee.

Bounded input mask (8 million voxels), input vertices (2.5 million per mesh), input faces (750k per mesh), 1–1024 sampled face centroids per direction (default 512), and finite triangle-search budgets; overly expensive workloads fail closed instead of publishing partial numbers. Exact search uses triangle centroid/radius pruning with an upper bound from a real target triangle. The per-direction maximum is named `max_sampled_mm` and is not labeled full-surface maximum. Deterministic for fixed input face order and software runtime. Quantiles describe sampled points, not a continuous area-weighted confidence interval. No arbitrary pass/fail clinical threshold or claim of superiority for one model/quality mode.

Tests: identical native half-voxel reference under anisotropic/rotated Patient LPS; displaced candidate; exact triangle-interior distance; ROI/acquisition boundary with virtual exterior; explicit sampling fraction; invalid mesh, affine and budgets fail closed. Use the qualified surface runtime through `VOXELATLAS_SURFACE_PYTHON` if the app venv lacks scipy/scikit-image. Real-study service binding, scalable exhaustive/stratified measurement evidence, synchronized 3-plane MPR and end-to-end qualification remain in 6G2–6G3/6H. Never print or upload source study or label data as diagnostic logs.
