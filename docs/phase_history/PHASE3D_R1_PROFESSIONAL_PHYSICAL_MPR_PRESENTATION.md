# Phase 3D-R1 - Professional Physical MPR Presentation

Phase 3D-R1 corrects the real MPR presentation exposed by anisotropic coronal CT acquisition and aligns the three MPR cards with the locked V1 target language.

- MPR display aspect is derived from patient-space physical extent, never raw raster width/height alone.
- Axial, coronal, and sagittal views remain generated from the Phase 3C canonical patient volume.
- Crosshair coordinates continue to represent shared patient LPS coordinates.
- Each view presents plane title, physical position, slice index, calibrated scale bar, orientation markers, and W/L controls.
- A center control returns the synchronized crosshair to patient-space volume center.
- A W/L control restores the modality default without modifying source data.
- No MRI appearance is fabricated for CT data.
- No patient-specific 3D anatomy is introduced in this step.
