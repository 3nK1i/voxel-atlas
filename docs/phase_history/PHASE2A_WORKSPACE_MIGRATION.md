# Phase 2A - Workspace migration

Phase 2A replaced the original standalone skull-demo presentation with an authenticated Three.js VoxelAtlas workspace and established the production viewer foundation.

The accepted Phase 2A behaviors that remain part of V1 are:

- Three.js interactive anatomy viewer
- ergonomic initial camera framing
- directional GPU clipping
- Clinical rendering
- opacity
- reset and auto rotate
- anatomical-layer architecture
- concise Login / Logout copy
- no AR/XR or visual-preset UI

Phase 2B intentionally supersedes the earlier prototype-specific behavior and retires both historical prototype trees from the current source. Historical source remains recoverable from Git history and the verified handoff archive.
